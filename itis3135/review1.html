Student Reviewed: Kowae, Marc

  • Website Checklist: The page has a clear site identity, working external links in the footer area, and a simple overall layout. The strongest first impression is the branded heading and the fact that the homepage is easy to recognize.
  • Contrast: The peach background with bright blue and purple text is readable, but the combination is visually harsh. A slightly darker body text color and fewer accent colors would improve readability and make the page feel more polished.
  • Repetition: The repeated heading style, centered layout, and repeated navigation separators create consistency. That part is working well and helps the page feel organized.
  • Alignment: The page is consistently centered, but almost everything is centered, including longer navigation lines. Left-aligning some text blocks or grouping links into smaller sections would make scanning easier.
  • Proximity: The heading, navigation, and footer links are grouped logically, but the main content area is very sparse. Adding a short welcome paragraph or a featured content section would make the page feel less empty.
  • Requirement Review - Working Navigation: The navigation menu shows several required pages, which is good progress. However, the links for Survey, Gallery, Inventory, and Highlight appear to route back to the homepage instead of separate pages, so those should be corrected before submission.
  • Requirement Review - Project Links: Project Overview and Project Page are present in the navigation, which is good. Make sure both pages are complete and visually consistent with the rest of the site.
  • Requirement Review - Professional Branding: The site has a memorable alliterative brand name and a designer link in the footer. That matches course expectations and gives the site personality.
  • Requirement Review - Footer Content: The footer includes useful academic and professional links plus the freeCodeCamp certification. That is a solid detail and helps establish credibility.
  • Accessibility Suggestion: Increase the navigation font size and spacing a bit. On the screenshot, the nav line looks compressed, which could be difficult for some users to read quickly.
  • Content Suggestion: Replace the short homepage sentence with a stronger introduction that explains what a visitor can find on the course site. Right now the landing page works, but it does not say much about the site itself.
  • Quality Control Suggestion: Review wording and labels such as CRAPPY Page so they match assignment expectations and tone. If the page is intentionally the CRAP assignment, you may still want to keep the label consistent and professional in the main navigation.
  • Stop, Start, Continue: Stop sending unfinished links to the homepage, start adding a little more structure and spacing to the home content, and continue using the strong branding and complete footer resources already in place.
