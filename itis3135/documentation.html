Brave Kudu Operations Documentation

This page models a technical documentation layout for training new helpers in the Brave Kudu Flavor Lab.

1. Prep Station Setup

  • Sanitize prep table and utensils before each shift.
  • Label all containers with ingredient name and prep date.
  • Keep dry and wet ingredients in separate zones.

2. Standard Flavor Mix

Base blend for one batch:

  • 2 cups cassava flour
  • 1 tsp smoked pepper
  • 1 tbsp baobab honey glaze

3. Service Workflow

  1. Receive order and confirm spice level.
  2. Cook batch and verify texture against quality checklist.
  3. Package item, attach label, and record inventory reduction.

4. Safety Rules

  • Use heat-resistant gloves when handling hot pans.
  • Discard oil after approved reuse cycle limit.
  • Report spills immediately and mark wet floor zones.
